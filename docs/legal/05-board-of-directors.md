# 05 取締役会・役員・登記

> **免責**: 本書は非公開会社である株式会社（主に取締役会設置会社・監査役設置会社）を対象とした一般的な要約であり、法的助言ではありません。監査等委員会設置会社・指名委員会等設置会社の特則は扱いません。個別案件は弁護士・司法書士に確認してください。
> **確認日**: 2026-11-11（e-Gov 法令検索 API で同日取得した現行条文、法務省ウェブサイトに基づく）
> **表記**: 「法」＝会社法、「施規」＝会社法施行規則。

## 1. 機関設計の前提

| ルール | 内容 | 根拠 |
|---|---|---|
| 取締役 | 株式会社には1人以上の取締役が必要 | 法326条1項 |
| 取締役会の設置義務 | 公開会社、監査役会設置会社、監査等委員会設置会社、指名委員会等設置会社。**非公開会社は任意** | 法327条1項 |
| 取締役会設置会社の取締役数 | **3人以上** | 法331条5項 |
| 取締役会設置会社の監査役 | 原則として監査役が必要。ただし**非公開会社で会計参与を置く場合は不要** | 法327条2項 |
| 会計限定監査役 | 非公開会社（監査役会設置会社・会計監査人設置会社を除く）は、監査役の監査範囲を**会計に関するものに限定**する旨を定款で定められる。登記事項 | 法389条1項、911条3項17号イ |
| 「監査役設置会社」の定義 | 会計限定の定めがある会社は、会社法上の「監査役設置会社」に**含まれない** | 法2条9号 |
| 非取締役会設置会社 | 業務は取締役の過半数で決定（定款で別段の定め可）。各取締役が会社を代表（代表取締役を定めた場合を除く） | 法348条、349条 |

**アプリ実装上の含意**: 会社設定として「取締役会設置の有無」「監査役の有無」「会計限定か否か」「公開／非公開」を持ち、以下のルールを分岐させる。会計限定監査役しかいない会社は、取締役会の招集通知先・書面決議の異議・議事録閲覧などで「監査役設置会社」向けの規定が適用されない点に注意が必要です。

## 2. 取締役会の権限（法362条）

- 職務（2項）: ①業務執行の決定、②取締役の職務執行の監督、③代表取締役の選定及び解職。
- **取締役に委任できない事項（4項）**: 次の事項**その他の重要な業務執行の決定**
  1. 重要な財産の処分及び譲受け
  2. 多額の借財
  3. 支配人その他の重要な使用人の選任及び解任
  4. 支店その他の重要な組織の設置、変更及び廃止
  5. 社債の募集に関する重要な事項
  6. 内部統制システム（業務の適正を確保するための体制）の整備（**大会社**である取締役会設置会社は決定義務。5項）
  7. 定款の定めに基づく役員等の責任の免除
- 「重要」「多額」の基準は法定されておらず、会社の規模等に応じた判断（取締役会規程で金額基準を定めるのが実務）。

## 3. 招集（法366条・368条）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 招集権者 | 各取締役。定款又は取締役会で招集権者を定めた場合はその取締役 | 法366条1項 |
| 他の取締役による招集請求 | 招集権者に目的事項を示して請求。請求の日から**5日以内**に、請求の日から**2週間以内**の日を会日とする招集通知が発せられなければ、請求した取締役が自ら招集可 | 法366条2項・3項 |
| 監査役による招集請求 | 取締役の不正行為等を報告する必要がある場合。同じく5日・2週間 | 法383条2項・3項 |
| **招集通知の期限** | 取締役会の日の**1週間前まで**（**定款で短縮可**。「3日前まで」とする会社が多い） | 法368条1項 |
| 通知先 | 各取締役。**監査役設置会社では各監査役にも** | 同上 |
| 通知の方法 | **制限なし**（書面でなくてよい。口頭・メール可。目的事項の特定も法律上は不要） | — |
| **招集手続の省略** | 取締役（監査役設置会社では取締役及び監査役）**全員の同意**があるとき | 法368条2項 |
| 株主による招集請求 | 監査役設置会社等**以外**の取締役会設置会社では、株主が取締役の違法行為等を理由に招集を請求できる | 法367条 |

## 4. 決議（法369条）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 定足数 | **議決に加わることができる取締役の過半数**の出席（定款で引上げ可、引下げ不可） | 法369条1項 |
| 可決要件 | **出席取締役の過半数**（定款で引上げ可、引下げ不可） | 同上 |
| 特別利害関係取締役 | 決議に特別の利害関係を有する取締役は**議決に加わることができない**。定足数の分母・分子からも除かれる | 同2項 |
| 代理出席・書面投票 | 条文上の規定はなく、認められないと解されています（株主総会と異なる） | — |
| Web 会議・電話会議 | 可能。議事録に「当該場所に存しない取締役等が出席した場合における当該出席の方法」を記載 | 施規101条3項1号 |
| 異議をとどめない取締役 | 決議に参加し議事録に異議をとどめない取締役は、決議に**賛成したものと推定** | 法369条5項 |
| 監査役の出席 | 監査役（会計限定を除く）は取締役会に出席し、必要があれば意見を述べる義務 | 法383条1項 |

- 特別利害関係の典型例: 代表取締役の解職決議における当該代表取締役、利益相反取引・競業取引の承認における当該取締役、自己に対する SO の割当て。代表取締役の**選定**における候補者本人は特別利害関係人に当たらないと解されています（解釈。条文上の明記なし）。
- **計算例**: 取締役5名のうち1名が特別利害関係人 → 議決に加わることができる取締役は4名 → 定足数は3名（過半数）→ 3名出席なら2名の賛成で可決。

## 5. 書面決議（決議の省略・法370条）

次の**全て**を満たすと、提案を可決する取締役会決議があったものとみなされます。

1. **定款に書面決議を認める定めがある**こと（株主総会の書面決議と異なり定款の定めが必須）
2. 取締役が決議の目的事項について提案をしたこと
3. 議決に加わることができる取締役の**全員**が**書面又は電磁的記録**により同意の意思表示をしたこと
4. **監査役設置会社では、監査役が当該提案について異議を述べていない**こと

- 同意の意思表示を記載・記録した書面又は電磁的記録は、**みなし決議の日から10年間**本店に備置き（法371条1項）。
- 議事録の作成も必要（施規101条4項1号。→ 7章）。
- 特別利害関係取締役は「議決に加わることができる取締役」に含まれないため、その同意は不要です。

## 6. 報告の省略（法372条）と3か月に1回の職務執行状況報告（法363条2項）

- 取締役・会計参与・監査役・会計監査人が、取締役（監査役設置会社では取締役及び監査役）の**全員に通知**した事項は、取締役会への報告を要しない（法372条1項）。
- **例外**: 代表取締役及び業務執行取締役による「**3か月に1回以上**の自己の職務執行状況の報告」（法363条2項）には、報告の省略は**適用されない**（法372条2項）。
- したがって取締役会設置会社は、**少なくとも3か月に1回は取締役会を実際に開催**（Web 会議等を含む）する必要があり、書面決議・報告省略だけで1年を回すことはできません。
- 競業取引・利益相反取引をした取締役は、取引後**遅滞なく**重要な事実を取締役会に報告（法365条2項）。

**アプリ実装上の含意**: 「直近の実開催取締役会（職務執行状況報告あり）から3か月」を超えそうな場合にアラートを出す。

## 7. 議事録（法369条3項・4項、施規101条）

### 7.1 記載事項（施規101条3項）
1. 開催された日時及び場所（当該場所に存しない取締役・監査役等が出席した場合は**その出席の方法**）
2. 特別取締役による取締役会であるときはその旨
3. 次のいずれかに該当するときはその旨: 取締役の請求を受けて招集されたもの（法366条2項）／請求した取締役が招集したもの（同3項）／株主の請求・招集によるもの（法367条）／監査役の請求・招集によるもの（法383条2項・3項）等
4. **議事の経過の要領及びその結果**
5. 決議事項について**特別の利害関係を有する取締役があるときは、その氏名**
6. 法定の意見・発言があるときはその内容の概要（競業・利益相反取引の事後報告（法365条2項）、監査役の報告・意見（法382条、383条1項）等）
7. 取締役会に出席した執行役、会計参与、会計監査人又は株主の氏名又は名称
8. 議長が存するときは議長の氏名

※ 出席した取締役・監査役は署名（記名押印）義務があるため、出席者として議事録上明らかになります。通常開催の議事録では「議事録作成者」は法定記載事項ではありません（株主総会議事録と異なる）。

### 7.2 書面決議・報告省略の場合（施規101条4項）

| 場合 | 記載事項 |
|---|---|
| 書面決議（法370条） | ①決議があったものとみなされた事項の内容、②提案をした取締役の氏名、③決議があったものとみなされた日、④**議事録の作成に係る職務を行った取締役の氏名** |
| 報告の省略（法372条1項） | ①報告を要しないものとされた事項の内容、②報告を要しないものとされた日、③議事録の作成に係る職務を行った取締役の氏名 |

### 7.3 署名・記名押印と電子署名

| 項目 | 内容 | 根拠 |
|---|---|---|
| 書面の議事録 | **出席した取締役及び監査役**が署名又は記名押印 | 法369条3項 |
| 電磁的記録の議事録 | 署名・記名押印に代わる措置として**電子署名**が必要 | 法369条4項、施規225条1項6号 |
| 電子署名の要件 | ①当該情報が措置を行った者の作成に係るものであることを示すためのものであること、②改変が行われていないかを確認できること | 施規225条2項 |
| 書面決議の議事録 | 出席者がいないため、法369条3項の署名義務は条文上生じない（実務上は作成取締役が記名押印・電子署名） | — |
| 登記の添付書面とする場合 | 登記申請に使用できる電子証明書の種類は法務省が指定。代表取締役の選定（重任を含む）を証する議事録については、変更前の代表取締役が商業登記電子証明書等で署名すれば、他の取締役は法務省が認めるその他の電子証明書（クラウド型電子署名サービス等）で足りる旨が案内されています | 法務省「商業・法人登記のオンライン申請について」 |

- 代表取締役選定議事録への押印（実印・印鑑証明書の要否、従前の代表取締役の届出印による例外）は商業登記規則61条の問題です。**同規則の条文本文は未確認**のため、司法書士に確認してください。

### 7.4 備置き・閲覧（法371条）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 備置き | 取締役会の日（書面決議はみなし決議の日）から**10年間**、議事録及び書面決議の同意書面等を**本店**に備置き | 法371条1項 |
| 株主の閲覧 | 権利行使のため必要があるとき、営業時間内いつでも請求可。ただし**監査役設置会社・監査等委員会設置会社・指名委員会等設置会社では裁判所の許可**が必要 | 同2項・3項 |
| 債権者の閲覧 | 役員等の責任追及のため必要があるとき、裁判所の許可を得て | 同4項 |
| 許可の制限 | 会社・親会社・子会社に著しい損害を及ぼすおそれがあるときは許可されない | 同6項 |

- 支店備置きの義務はありません（株主総会議事録と異なる）。
- 会計限定監査役しかいない会社は「監査役設置会社」に当たらないため、株主は裁判所の許可なく閲覧請求できます。

## 8. 競業取引・利益相反取引（法356条・365条）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 対象 | ①取締役が自己又は第三者のためにする会社の事業の部類に属する取引（**競業取引**）、②取締役が自己又は第三者のために会社とする取引（**直接取引**）、③会社が取締役の債務を保証する等、取締役以外の者との間の会社と取締役の利益が相反する取引（**間接取引**） | 法356条1項 |
| 承認機関 | 取締役会設置会社: **取締役会**／非設置会社: **株主総会**（普通決議）。重要な事実を開示して承認を受ける | 法356条1項、365条1項 |
| 事後報告 | 取締役会設置会社では、取引後**遅滞なく**重要な事実を取締役会に報告 | 法365条2項 |
| 議決 | 当該取締役は特別利害関係人として議決に加われない | 法369条2項 |
| 任務懈怠の推定等 | 利益相反取引により会社に損害が生じた場合の任務懈怠の推定、競業取引の損害額の推定 | 法423条2項・3項 |

スタートアップで典型的な該当例: 取締役個人から会社への貸付（無利息・無担保は不要と解される）、取締役が代表を務める別会社との取引、取締役の借入に対する会社保証、取締役への SO 付与は報酬規制（法361条）の問題。

## 9. 役員の任期（法332条・336条）と重任登記

| 役員 | 原則 | 非公開会社の特則 | 根拠 |
|---|---|---|---|
| 取締役 | 選任後**2年以内**に終了する事業年度のうち最終のものに関する定時株主総会の終結の時まで（定款・株主総会決議で**短縮可**） | **定款で選任後10年以内**に終了する事業年度のうち最終のものに関する定時株主総会の終結の時まで伸長可 | 法332条1項・2項 |
| 監査役 | 選任後**4年以内**に終了する事業年度のうち最終のものに関する定時株主総会の終結の時まで（**短縮不可**。補欠の例外あり） | 定款で**10年**まで伸長可 | 法336条1項〜3項 |

- 任期は「定時株主総会の終結の時」に満了します。定時総会を書面決議（法319条1項）で行った場合は、目的事項全ての決議が成立した時に終結（法319条5項）。
- **任期が当然に満了する定款変更**（法332条7項、336条4項）: 監査等委員会・指名委員会等を置く定款変更、**全部の株式の譲渡制限を廃止する定款変更（＝公開会社になる場合）**、監査役設置の廃止、会計限定の定めの廃止 等。
- **重任（再任）でも変更登記が必要**です（法務省も「再任の方も必要です」と注意喚起）。任期10年の会社は登記を失念しやすい。
- 欠員の場合: 任期満了・辞任により退任した役員は、後任者が就任するまで**なお役員としての権利義務を有する**（法346条1項）。この場合、退任登記は後任者就任まで申請できず、選任懈怠の過料（法976条22号）の対象にもなり得ます。
- 役員の選任・解任は株主総会普通決議（定足数は定款でも1/3未満にできない。法341条）。監査役の解任は特別決議（法309条2項7号）。

**アプリ実装上の含意**: 役員ごとに「選任日」「定款上の任期年数」「事業年度末日」から任期満了となる定時総会を算出し、当該定時総会の議題に役員改選を自動提案する。定時総会終結日から2週間の登記期限を管理する。

## 10. 役員変更等の登記と過料

| 項目 | 内容 | 根拠 |
|---|---|---|
| 登記期限 | 登記事項に変更が生じたときから**2週間以内**に本店所在地で変更登記 | 法915条1項 |
| 役員に関する登記事項 | 取締役の氏名、代表取締役の氏名及び**住所**、取締役会設置会社である旨、監査役設置会社である旨・監査役の氏名・会計限定の定め 等 | 法911条3項13号〜17号 |
| **登記懈怠の過料** | 登記を怠ったときは**100万円以下の過料**（代表者個人に科される） | 法976条1号 |
| 登録免許税 | 役員変更: 申請1件につき3万円（**資本金1億円以下の会社は1万円**） | 登録免許税法 別表第一 第24号(一)カ |
| 添付書面 | 株主総会議事録・取締役会議事録（書面決議の場合は「該当することを証する書面」）、株主リスト、就任承諾書 等 | 商業登記法46条、商業登記規則61条 |

## 11. 休眠会社のみなし解散（法472条）

- **最後の登記から12年**を経過した株式会社（休眠会社）は、法務大臣が官報公告で「**2か月以内**に事業を廃止していない旨の届出をすべき旨」を公告し、登記所から通知を発する。期間内に届出も登記もしないと、**2か月の期間満了時に解散したものとみなされる**（法472条1項・2項）。
- 法務省によれば、平成26年度以降**毎年**整理作業が実施され、毎年10月頃に官報公告・通知が行われています。
- みなし解散後**3年以内**に限り、株主総会の決議（特別決議。法309条2項11号）で会社を継続できる（法473条）。
- 非公開会社で役員任期を最長10年にしても、12年以内には必ず役員変更登記が発生する設計になっています。
