# 03 新株予約権・ストックオプション

> **免責**: 本書は非公開会社である株式会社を主な対象とした一般的な要約であり、法的助言・税務助言ではありません。税制適格の判定は個別の契約・事実関係に依存します。必ず税理士・弁護士に確認してください。
> **確認日**: 2026-11-11（e-Gov 法令検索 API で同日取得した現行条文、国税庁・経済産業省の公開資料に基づく）
> **表記**: 「法」＝会社法、「措法」＝租税特別措置法、「措令」＝同施行令、「措規」＝同施行規則、「産競法」＝産業競争力強化法、「SO」＝ストックオプション。

## 1. 新株予約権の内容（法236条1項）

発行時に次の事項を新株予約権の内容として定めます。

| 号 | 事項 |
|---|---|
| 1 | 目的である株式の数（種類株式発行会社は種類及び種類ごとの数）又はその算定方法 |
| 2 | 行使に際して出資される財産の価額（**行使価額**）又はその算定方法 |
| 3 | 金銭以外の財産を出資の目的とするときは、その旨・財産の内容及び価額 |
| 4 | **行使期間** |
| 5 | 行使により株式を発行する場合の増加する資本金及び資本準備金に関する事項 |
| 6 | 譲渡による取得について会社の承認を要するときは、その旨（**譲渡制限新株予約権**） |
| 7 | 取得条項（一定の事由が生じたことを条件に会社が取得できる）を付すときは、その事由・対価等 |
| 8 | 合併・会社分割・株式交換・株式移転の際に存続会社等の新株予約権を交付するときは、その旨及び条件 |
| 9 | 行使により交付する株式に1株未満の端数がある場合に切り捨てるときは、その旨 |
| 10・11 | 新株予約権証券を発行するときはその旨 等 |

- 「行使の条件」（在籍要件・上場要件・ベスティング等）は236条1項の列挙事項ではありませんが、定めた場合は登記事項になります（法911条3項12号ニ）。
- 行使期間の初日が到来している新株予約権の目的株式数は、発行可能株式総数の枠内に収まっている必要があります（法113条4項）。

## 2. 募集事項の決定（法238条〜240条）

### 2.1 募集事項（法238条1項）
1. 募集新株予約権の内容及び数
2. 金銭の払込みを要しないとする場合は、その旨（無償発行）
3. 有償の場合は払込金額又はその算定方法
4. **割当日**
5. 払込期日を定めるときはその期日
6・7. 新株予約権付社債に関する事項

募集事項は募集ごとに均等に定める（法238条5項）。

### 2.2 決定機関

| 場面 | 非公開会社 | 根拠 |
|---|---|---|
| 募集事項の決定 | **株主総会の特別決議** | 法238条2項、309条2項6号 |
| 取締役（会）への委任 | 株主総会特別決議で委任可。①委任できる新株予約権の**内容及び数の上限**、②無償とする場合はその旨、③有償の場合は**払込金額の下限**を定める | 法239条1項、309条2項6号 |
| 委任の有効期間 | **割当日が決議の日から1年以内**の募集についてのみ有効 | 法239条3項 |
| 有利発行 | 無償とすること又は払込金額が特に有利な場合、取締役が株主総会で理由を説明 | 法238条3項、239条2項 |
| 目的株式が譲渡制限種類株式 | 当該種類の種類株主総会の特別決議も必要（定款で不要とする定めがある場合等を除く） | 法238条4項、239条4項、324条2項3号 |
| 公開会社（参考） | 取締役会決議（有利発行を除く）。割当日の2週間前までに株主へ通知又は公告 | 法240条 |

**注意**: 通常の委任（法239条）では、新株予約権の「内容」（行使価額・行使期間を含む）は株主総会で定める必要があり、取締役会に委任できるのは内容以外の募集事項（割当日・個数の確定等）です。

### 2.3 産業競争力強化法による特例（いわゆるストックオプション・プール）

産競法21条の19（令和6年9月2日施行の改正で創設。施行日は経済産業省の公表資料で確認）:

- **設立の日以後の期間が15年未満**の株式会社が、省令の要件に該当することについて**経済産業大臣及び法務大臣の確認**を受けた場合、
- 法239条1項の委任において、新株予約権の内容のうち**行使価額（法236条1項2号）と行使期間（同4号）を取締役（会）に委任**でき、
- 法239条2項・**3項（1年の期間制限）は適用されない**（1項）。
- 委任に基づき取締役（会）が募集事項を定めたときは、**割当日の2週間前まで**に株主へ通知（3項）。
- 有利発行に当たる場合は、株主総会特別決議で行使価額・行使期間・個数の上限・割当日を決議日から1年以内とする旨を定める（4項）。
- 確認の具体的要件（省令）・手続は本書では未確認です。経済産業省の制度ページを参照してください。

## 3. 割当て・総数引受契約・新株予約権者となる日

| 項目 | 内容 | 根拠 |
|---|---|---|
| 割当ての決定 | 目的株式が譲渡制限株式である場合、又は譲渡制限新株予約権である場合は、**株主総会（取締役会設置会社は取締役会）**の決議。定款で別段の定め可。割当日の前日までに通知 | 法243条2項・3項 |
| 総数引受契約 | 申込み・割当て手続は不要。上記と同じ場合には株主総会（取締役会設置会社は取締役会）による**契約の承認**が必要 | 法244条1項・3項 |
| 新株予約権者となる日 | **割当日** | 法245条1項 |
| 有償の場合の払込期限 | 行使期間の初日の前日（払込期日を定めた場合はその期日）まで。払い込まないと行使できない | 法246条1項・3項 |

- 非取締役会設置会社で法243条2項・244条3項の決議を株主総会で行う場合は特別決議（法309条2項6号）。

## 4. 新株予約権原簿（法249条〜252条）

会社は新株予約権を発行した日以後**遅滞なく**原簿を作成し、次を記載します（無記名式証券を発行しない通常の場合。法249条3号）。

| # | 記載事項 |
|---|---|
| イ | 新株予約権者の氏名又は名称及び住所 |
| ロ | その有する新株予約権の内容及び数 |
| ハ | 新株予約権を取得した日 |
| ニ・ホ | 証券発行新株予約権・証券発行新株予約権付社債の場合は証券の番号 |

- 新株予約権者は原簿記載事項証明書の交付を請求できる（法250条。代表取締役の署名又は記名押印／電子署名）。
- 原簿は本店（株主名簿管理人がある場合はその営業所）に備え置き、**株主及び債権者**は理由を明らかにして閲覧・謄写を請求できる。拒絶事由は株主名簿と同様（法252条）。

## 5. 譲渡・行使・消滅

| 項目 | 内容 | 根拠 |
|---|---|---|
| 譲渡 | 原則自由。譲渡制限新株予約権は会社の承認（株主総会／取締役会設置会社は取締役会。新株予約権の内容として別段の定め可）が必要 | 法254条、262条、265条 |
| 行使の方法 | 行使する新株予約権の内容及び数、行使する日を明らかにして行う | 法280条1項 |
| 行使時の払込み | **行使日に**、会社が定めた銀行等の払込取扱場所で行使価額の全額を払い込む。会社に対する債権との相殺不可 | 法281条1項・3項 |
| 株主となる日 | **行使した日** | 法282条1項 |
| 消滅 | 新株予約権者が**行使することができなくなったとき**は消滅する（行使期間満了、行使条件を満たさないことの確定、退職による失権等） | 法287条 |
| 自己新株予約権 | 会社は自己新株予約権を行使できない。消却は取締役会設置会社では取締役会決議 | 法280条6項、276条 |

**アプリ実装上の含意**: 退職等で「行使できなくなった」場合は法287条により当然消滅し、消滅分は変更登記（2週間以内）の対象。会社が無償取得して消却する設計（取得条項）もあるため、「失効（287条消滅）」「取得」「消却」「放棄」を区別して記録する。

## 7. 取締役への付与と報酬決議（法361条）

取締役に SO を付与する場合、募集事項の決定とは別に、報酬等としての株主総会決議（普通決議）又は定款の定めが必要です。

| 号 | 定める事項 |
|---|---|
| 1 | 額が確定している報酬等: その額 |
| 2 | 額が確定していない報酬等: 具体的な算定方法 |
| 3 | 募集株式を報酬とする場合: 数の上限その他法務省令で定める事項 |
| **4** | **募集新株予約権を報酬とする場合: 数の上限その他法務省令で定める事項**（施規98条の3。本書では条文未確認） |
| 5 | 募集株式・募集新株予約権と引換えにする払込みに充てるための金銭を報酬とする場合（いわゆる相殺構成）: 数の上限等 |
| 6 | 金銭でないもの（株式・新株予約権を除く）: 具体的な内容 |

- 議案を提出した取締役は、株主総会で当該事項を相当とする理由を説明する（法361条4項）。
- 監査役への付与は法387条（報酬決議）による。従業員への付与には報酬決議は不要。
- 付与対象者が取締役である取締役会決議（割当先の決定等）では、当該取締役は特別利害関係人として議決に加われない場合があります（法369条2項）。→ `05-board-of-directors.md`

## 8. 税制適格ストックオプション（措法29条の2）

### 8.1 制度の効果
- 権利行使時の経済的利益（行使時時価 − 行使価額）に対する給与所得課税を行わず、**株式売却時**に（売却価額 − 行使価額）を株式譲渡所得として課税（措法29条の2第1項、国税庁 Q&A 問6）。

### 8.2 要件一覧（2026-11-11時点の現行条文）

| # | 要件 | 数値・内容 | 根拠 |
|---|---|---|---|
| 1 | 発行形態 | 会社法238条2項の決議（239条の委任に基づく決定、240条の取締役会決議を含む）に基づき、**金銭の払込み（金銭以外の資産の給付を含む）をさせないで発行**された新株予約権（＝無償発行） | 措法29条の2第1項、措令19条の3第1項 |
| 2 | 付与対象者 | 付与決議のあった株式会社又はその**50%超を直接・間接に保有する法人（子会社等）**の**取締役・執行役・使用人**である個人、及びその権利承継相続人。**監査役は含まれない**（条文上列挙されていない）。加えて一定の社外高度人材（→8.5） | 措法29条の2第1項、措令19条の3第2項 |
| 3 | 大口株主の除外 | 付与決議日に、**未上場会社: 発行済株式総数の1/3超**、**上場会社・店頭登録会社: 1/10超**を有していた個人、及びその**特別関係者**（親族、事実婚の相手方とその直系血族、大口株主から受ける金銭等で生計を維持する者 等）は対象外 | 措法29条の2第1項、措令19条の3第3項・4項 |
| 4 | 付与契約 | 付与決議に基づき会社と対象者との間で締結された契約に、下記5〜10の要件が**定められている**こと。その契約に従って行使すること | 措法29条の2第1項柱書 |
| 5 | 権利行使期間 | **付与決議の日後2年を経過した日**から**付与決議の日後10年を経過する日**まで。付与決議日において**設立後5年未満**かつ**未上場（上場・店頭登録していない）**の会社は**15年を経過する日**まで | 措法29条の2第1項1号、措規11条の3第2項 |
| 6 | 年間権利行使価額の上限 | 権利行使価額の年間合計額が**1,200万円**を超えないこと。ただし判定上、権利行使価額を次のとおり除して計算する（→8.3） | 措法29条の2第1項ただし書・2号 |
| 7 | 行使価額 | 1株当たりの権利行使価額が、**付与契約締結時における1株当たりの価額以上**であること（→8.4） | 同3号 |
| 8 | 譲渡禁止 | 新株予約権の**譲渡をしてはならない**こととされていること | 同4号 |
| 9 | 会社法適合 | 行使に係る株式の交付が、付与決議がされた会社法238条1項に定める事項に反しないで行われること | 同5号 |
| 10 | 株式の保管・管理 | 行使により取得する株式について、次の**いずれか**: **(イ)** 会社と証券会社（第一種金融商品取引業者）又は信託会社等との間であらかじめ締結された取決めに従い、取得後直ちに振替口座簿への記載・保管の委託・管理等信託がされること、**(ロ)** 会社と付与対象者との間であらかじめ締結された取決めに従い、取得後直ちに**発行会社自身が株式（譲渡制限株式に限る）を管理**すること（権利者別の契約、帳簿を備えて区分管理 等） | 同6号、措令19条の3第6項・7項以下 |
| 11 | 行使時の書面提出 | 行使の際、権利者が ①付与決議日に大口株主・その特別関係者でなかった旨の誓約書面、②その年の他の特定新株予約権の行使の有無（あれば行使価額・行使年月日）等を記載した書面を会社に提出（電磁的方法可）。会社は保存義務 | 措法29条の2第2項・3項 |

### 8.3 年間権利行使価額の上限の区分（令和6年度改正。令和6年分以後の所得税に適用）

| 付与決議日における会社の状況 | 計算方法 | 実質的な年間上限 | 根拠 |
|---|---|---|---|
| 設立の日以後の期間が**5年未満** | 権利行使価額 ÷ 2 | **2,400万円** | 措法29条の2第1項ただし書 |
| 設立の日以後の期間が**5年以上20年未満**で、かつ ①**未上場**、又は ②**上場（店頭登録）の日以後5年未満**の上場会社 | 権利行使価額 ÷ 3 | **3,600万円** | 同、措規11条の3第1項 |
| 上記以外 | そのまま | **1,200万円** | 同 |

- 区分は**付与決議の日**時点で判定します（行使時ではない）。5年未満の区分には条文上、上場・未上場の別はありません。
- 端数処理: 1回の権利行使における権利行使価額の合計額ごとに2又は3で除し、**1円未満の端数は切上げ**（経済産業省ウェブサイト・国税庁 Q&A。法令ではなく運用上の取扱いとして公表）。
- 超過した場合、**超過することとなる行使に係る経済的利益の全体**が非課税の対象外となります（措法29条の2第1項ただし書。超過部分のみではない点に注意）。
- 他社から付与された特定新株予約権も含め、その年の行使分を通算します。

### 8.4 行使価額と付与時の株価（国税庁通達・Q&A）

- 措法29条の2第1項3号の「契約の締結の時における一株当たりの価額」の算定方法は、令和5年7月7日付の措置法通達改正（課個2-20ほか）で明確化されました。
- **原則方式**: 所得税基本通達23〜35共-9の例（売買実例→類似会社比準→純資産価額等を参酌した価額 等）。
- **特例方式（セーフハーバー）**: **取引相場のない株式**については、一定の条件の下、**財産評価基本通達の例**（類似業種比準方式・純資産価額方式等）により算定した価額以上を行使価額としていれば要件を満たす（Q&A 問7）。この特例方式は**税制適格 SO の行使価額要件の判定にのみ**使用可能。
- 特例方式の主な留意点（Q&A 問7〜9）:
  - 純資産価額は直前期末決算に基づいて算定して差し支えないが、①付与契約日が直前期末から**6か月を経過**し、かつ純資産価額が直前期末の**2倍を超える**場合、②直前期末以降に株式を発行している場合は、仮決算又は払込金額の加算が必要。
  - 純資産価額がマイナスの場合の株価は0円となるが、行使価額は**備忘価額1円以上**とする。
  - 発行済株式数は**付与時**の株式数。
  - 種類株式を発行している場合は、優先株式の**残余財産優先分配額を控除**して普通株式の価額を算定（優先分配額が投資額の1.5倍・2倍等でも同様）。J-KISS 型新株予約権など残余財産の優先分配を受けられるものは優先株式として取り扱って差し支えない。
  - 中心的な同族株主に該当する者への付与は「小会社」として算定、土地・上場有価証券は契約時の価額による、評価差額に対する法人税額等相当額は控除しない。
- 「契約の締結の時」は、付与契約の締結日が付与決議日・募集事項決定決議日から**6か月を経過していない**場合、これらの決議日として差し支えない（Q&A 問7注）。
- 契約変更: 付与契約で定めた事項を変更すると原則として税制適格に該当しなくなる（Q&A 問10。要件と無関係な変更等の例外あり）。

### 8.5 社外高度人材（特定従事者）
- 中小企業等経営強化法の**認定社外高度人材活用新事業分野開拓計画**に従って新株予約権を付与される社外高度人材（取締役・使用人以外の個人）も対象（措法29条の2第1項）。
- 追加要件: 計画の実施時期の開始等の日から行使日まで**引き続き居住者**であること、国外転出時の会社への通知（同7号）、認定取消し時の会社からの通知（同8号）、行使時の居住者である旨の誓約書面（同2項2号）等。
- 令和6年度改正で認定対象企業・社外高度人材の範囲が拡充された旨が経済産業省ページに記載されています。**具体的な人材要件・認定手続は本書では未確認**です。

## 9. 有償 SO・信託型 SO の税務（国税庁 Q&A 令和5年5月公表、最終改訂 令和6年11月）

| 類型 | 付与時 | 行使時 | 株式売却時 | Q&A |
|---|---|---|---|---|
| 税制非適格（無償・有利発行型） | 課税なし | **給与所得**（行使時株価 − 行使価額）。会社に**源泉徴収義務** | 譲渡所得（売却価額 − 行使時株価） | 問1 |
| **有償型**（適正な時価で有償取得） | 課税なし（時価で購入） | **課税なし**（所得税法上、行使時の経済的利益を認識しない） | 譲渡所得（売却価額 −（SO 購入価額 + 行使価額）） | 問2 |
| **信託型（税制非適格）** | 役職員への付与時は課税なし | **給与所得として課税**（行使時株価 −（信託が負担した取得価額 + 行使価額））。会社に源泉徴収義務 | 譲渡所得（売却価額 − 行使時株価） | 問3 |
| 税制適格 | 課税なし | 課税繰延べ | 譲渡所得（売却価額 − 行使価額） | 問6 |
| 信託型で税制適格要件を満たすもの | — | 一定の要件（受託者が自己の判断で行使・譲渡できないこと、無償付与、受益者指定日後2年〜10年（15年）の行使、年間上限 等）を満たせば税制適格として認められる | — | 問12 |

- 国税庁は信託型（税制非適格）について、「実質的には発行会社が役職員に付与しており、役職員に金銭等の負担がないことなどから、経済的利益は労務の対価に当たり**給与として課税される**」との見解を示しています（Q&A 問3 注3）。
- 請負契約等に基づく役務提供の対価として付与された SO の経済的利益は事業所得又は雑所得（Q&A 問1 注2）。
- 源泉所得税の納付については Q&A 問4 を参照。

## 10. 金融商品取引法との関係

- 自社・子会社の役員・使用人への**譲渡禁止付き**新株予約権の付与は、50名以上への勧誘でも有価証券届出書は不要（金商法施行令2条の12第2号）。2027年4月1日以降は「募集」の定義から除外される改正が施行予定。→ `02-share-issuance.md` 7章
