## 1. 募集株式の発行（第三者割当増資）の手続（法199条〜213条）

### 1.1 募集事項（法199条1項）
1. 募集株式の数（種類株式発行会社は種類及び数）
2. 払込金額又はその算定方法
3. 現物出資の場合はその旨、財産の内容及び価額
4. 払込期日又は払込期間
5. 増加する資本金及び資本準備金に関する事項

### 1.2 決定機関

| 場面 | 非公開会社 | 公開会社（参考） | 根拠 |
|---|---|---|---|
| 募集事項の決定 | **株主総会の特別決議** | 取締役会（有利発行を除く） | 法199条2項、309条2項5号、201条1項 |
| 取締役（会）への委任 | 株主総会特別決議で委任可。**募集株式数の上限**と**払込金額の下限**を定める | 適用なし | 法200条1項、309条2項5号 |
| 委任の有効期間 | 払込期日（期間を定めた場合はその末日）が**決議の日から1年以内**の募集に限り有効 | — | 法200条3項 |
| 有利発行 | 取締役が株主総会で理由を説明 | 株主総会特別決議が必要 | 法199条3項、200条2項 |
| 譲渡制限種類株式の募集 | 当該種類の**種類株主総会の特別決議**も必要（定款で不要とする定めがある場合、議決権を行使できる種類株主がいない場合を除く） | 同左 | 法199条4項、200条4項、324条2項2号 |
| 株主割当て | 原則株主総会特別決議。定款の定めにより取締役の決定／取締役会決議も可。申込期日の**2週間前まで**に株主へ通知 | 取締役会 | 法202条3項・4項、309条2項5号 |

### 1.3 申込み・割当て・総数引受契約

| 方式 | 内容 | 根拠 |
|---|---|---|
| 申込み＋割当て | 会社が申込者の中から割当先と数を決定。募集株式が**譲渡制限株式**の場合、割当ての決定は**株主総会（取締役会設置会社は取締役会）**。定款で別段の定め可。払込期日（期間の初日）の**前日まで**に割当数を通知 | 法203条、204条 |
| **総数引受契約** | 引受人が募集株式の総数を引き受ける契約を締結する場合、申込み・割当ての手続（法203条・204条）は不要。募集株式が**譲渡制限株式**のときは、**株主総会（取締役会設置会社は取締役会）による契約の承認**が必要。定款で別段の定め可 | 法205条1項・2項 |

- 非取締役会設置会社が法204条2項・205条2項の決議を株主総会で行う場合は**特別決議**（法309条2項5号）。
- スタートアップの増資は「総数引受契約方式」が一般的で、同日に ①株主総会（募集事項決定・総数引受契約承認）→ ②契約締結 → ③払込み、とすることも可能です。

### 1.4 払込み・効力発生

| 項目 | 内容 | 根拠 |
|---|---|---|
| 払込み | 払込期日又は払込期間内に、会社が定めた銀行等の払込取扱場所で**全額**払込み | 法208条1項 |
| 相殺禁止 | 引受人は払込債務と会社に対する債権を相殺できない（DES は現物出資として構成） | 法208条3項 |
| 失権 | 出資を履行しないと株主となる権利を失う | 法208条5項 |
| 株主となる日 | 払込**期日**を定めた場合は**当該期日**／払込**期間**を定めた場合は**出資の履行をした日** | 法209条1項 |
| 差止め | 法令・定款違反又は著しく不公正な方法による発行は、不利益を受けるおそれのある株主が差止請求可 | 法210条 |

**アプリ実装上の含意**: 株主名簿の「取得日」は法209条1項に従って決定する（期日方式なら期日、期間方式なら各人の入金日）。

## 2. 資本金・資本準備金（法445条）

- 原則: 払込み・給付された財産の額の**全額が資本金**（1項）。
- **1/2ルール**: 払込額の**2分の1を超えない額**は資本金として計上しないことができ（2項）、計上しない額は**資本準備金**としなければならない（3項）。
- つまり `資本金増加額 ≥ 払込総額 × 1/2`、`資本準備金増加額 = 払込総額 − 資本金増加額`。
- 自己株式の処分では資本金は増加しません。
- 新株予約権の行使時も同様のルール（法236条1項5号で発行時に定める）。厳密な資本金等増加限度額の計算は会社計算規則14条・17条（本書では条文未確認）。

## 3. 発行可能株式総数（法113条・37条）

| ルール | 内容 | 根拠 |
|---|---|---|
| 廃止不可 | 発行可能株式総数の定めを廃止することはできない | 法113条1項 |
| 減少の下限 | 減少後の発行可能株式総数 ≥ 発行済株式総数 | 同2項 |
| **4倍ルール** | **公開会社**が発行可能株式総数を増加する場合、及び**非公開会社が公開会社となる**定款変更をする場合、発行可能株式総数 ≤ 発行済株式総数×4。**非公開会社のままなら4倍制限なし** | 同3項 |
| 設立時 | 設立時発行株式総数 ≥ 発行可能株式総数×1/4。非公開会社は適用なし | 法37条3項 |
| 新株予約権との関係 | 行使期間が到来している新株予約権の行使で交付される株式数 ≤ 発行可能株式総数 −（発行済株式総数 − 自己株式数） | 法113条4項 |
| 種類株式 | 種類ごとの発行可能種類株式総数にも同様の枠管理がある | 法114条 |

- 発行可能株式総数の変更は定款変更（株主総会特別決議。法466条、309条2項11号）で、登記事項（法911条3項6号）。
- **アプリのバリデーション**: `発行済 + 今回発行 ≤ 発行可能`、種類ごとに `発行済種類株式 + 今回発行 ≤ 発行可能種類株式総数`、新株予約権・取得請求権付株式の潜在株式分の枠確保。

## 4. 種類株式（法108条）

### 4.1 内容を異にできる9事項（法108条1項）

| 号 | 事項 | スタートアップでの典型例 |
|---|---|---|
| 1 | 剰余金の配当 | 優先配当 |
| 2 | 残余財産の分配 | 残余財産優先分配（1倍・参加型／非参加型） |
| 3 | 議決権を行使できる事項 | 議決権制限株式 |
| 4 | 譲渡による取得について会社の承認を要すること | 譲渡制限 |
| 5 | 株主から会社への取得請求（取得請求権付株式） | 普通株式への転換請求権 |
| 6 | 一定の事由が生じたことを条件とする会社による取得（取得条項付株式） | 上場申請決議時の普通株式への強制転換 |
| 7 | 株主総会決議による全部取得（全部取得条項付種類株式） | — |
| 8 | 種類株主総会の決議を必要とする事項（いわゆる拒否権） | 重要事項の拒否権 |
| 9 | 種類株主総会における取締役・監査役の選任 | 役員選任権付株式。**公開会社及び指名委員会等設置会社は発行不可**（1項ただし書） |

- 種類株式を発行するには、各種類の内容と**発行可能種類株式総数**を定款で定める（法108条2項）。登記事項（法911条3項7号）。
- 非公開会社は、種類株式とは別に、剰余金配当・残余財産分配・議決権について**株主ごとに異なる取扱い（属人的定め）**を定款で定められる（法109条2項）。その定款変更は**総株主の半数以上かつ総株主の議決権の4分の3以上**の特殊決議（法309条4項）。

### 4.2 種類株主総会

| 場面 | 決議要件 | 根拠 |
|---|---|---|
| ある種類の株主に**損害を及ぼすおそれ**がある一定の行為（株式の種類の追加、株式の内容の変更、発行可能株式総数・発行可能種類株式総数の増加、株式併合・分割、株式無償割当て、株主割当てによる株式・新株予約権の募集、新株予約権無償割当て、合併等の組織再編 ほか） | 当該種類の種類株主総会の**特別決議**がなければ効力を生じない | 法322条1項、324条2項4号 |
| 上記を定款で不要とする定め | 可能（ただし株式の種類の追加等、1項1号の定款変更（単元株式数を除く）には引き続き必要）。発行後に定めるには当該種類株主**全員の同意** | 法322条2項〜4項 |
| 譲渡制限種類株式の募集・その新株予約権の募集 | 当該種類の種類株主総会の特別決議（定款で不要とできる） | 法199条4項、238条4項、324条2項2号・3号 |
| 拒否権（法108条1項8号）の対象事項 | 定款所定の種類株主総会決議 | 法323条 |
| 種類株主総会の普通決議 | その種類の総株主の議決権の過半数を有する株主が出席し、出席株主の議決権の過半数 | 法324条1項 |
| 種類株主総会の特別決議 | 議決権を行使できる株主の議決権の過半数（定款で1/3以上に緩和可）が出席し、出席株主の議決権の**2/3以上** | 法324条2項 |
| ある種類に譲渡制限を新設する定款変更 | 当該種類株主の**半数以上**かつ議決権の**2/3以上** | 法111条2項、324条3項1号 |
| 取得条項を新設・変更する定款変更 | 当該種類株主**全員の同意** | 法111条1項 |

**実務メモ**: シリーズAで新たな種類株式を追加する場合、既存種類株主に「損害を及ぼすおそれ」があるかの判断を避けるため、保守的に全種類の種類株主総会決議（又は種類株主全員の書面同意。法325条による319条の準用）を取得することが多いです。

## 5. 登記（法911条・915条）と登録免許税

| 項目 | 内容 | 根拠 |
|---|---|---|
| 変更登記の期限 | 登記事項に変更が生じたときから**2週間以内**に本店所在地で変更登記 | 法915条1項 |
| 払込期間を定めた場合 | 当該**期間の末日現在**により、末日から2週間以内で足りる | 法915条2項 |
| 新株予約権の行使・取得請求権付株式の取得請求による変更 | **毎月末日現在**により、当該末日から2週間以内で足りる | 法915条3項 |
| 増資で変わる登記事項 | 資本金の額（5号）、発行済株式の総数並びに種類及び種類ごとの数（9号）。必要に応じ発行可能株式総数（6号）、発行する各種類の株式の内容・発行可能種類株式総数（7号） | 法911条3項 |
| 登記懈怠 | **100万円以下の過料** | 法976条1号 |

**登録免許税（登録免許税法 別表第一 第24号(一)）**

| 登記 | 税額 |
|---|---|
| 資本金の増加（ニ） | 増加した資本金の額の**1000分の7**（計算額が**3万円未満のときは申請1件につき3万円**） |
| 新株予約権の発行（ヌ） | 申請1件につき**9万円** |
| 役員変更（カ） | 申請1件につき3万円（**資本金1億円以下の会社は1万円**） |
| その他の登記事項の変更（ツ）（発行可能株式総数、種類株式の内容、新株予約権の行使・消滅等） | 申請1件につき**3万円** |

- 資本準備金に計上した額には登録免許税がかかりません（課税標準は「増加した資本金の額」）。
- 例: 払込総額1億円、資本金5,000万円・資本準備金5,000万円 → 5,000万円×0.7%＝35万円（＋種類株式の内容変更等があれば区分ごとに加算）。

## 6. J-KISS（転換型新株予約権／コンバーティブル・エクイティ）の概要

J-KISS は Coral Capital（旧 500 Startups Japan）が無償公開しているシード投資用の投資契約書ひな形で、法形式は**有償で発行する新株予約権**です。2016年4月に v1.0、**2022年4月に v2.0** が公開されています（Coral Capital 公式ページで確認。2026-11-11時点で最新版は v2.0 系と記載）。

### 6.1 ひな形（J-KISS 2.0, v2.01）の主要条件
以下の数値は**ひな形のブラケット（[ ]）内の初期値**であり、案件ごとに変更され得ます。アプリでは契約ごとのパラメータとして保持してください。

| 項目 | ひな形の定め | 備考 |
|---|---|---|
| 次回株式資金調達（適格資金調達） | 転換により発行される株式の発行総額を除く総調達額が **[1億円] 以上**の株式発行 | 発生すると転換（行使）可能 |
| 転換価額（適格調達時） | 次のうち**低い方**: (x) 次回調達の1株当たり発行価額 × **[0.8]**（＝20%ディスカウント）、(y) バリュエーションキャップ ÷ 完全希釈化後株式数 | |
| バリュエーションキャップ | **ポストマネー基準**（v2.0 で変更。v1.x 系はプレマネー基準） | v1.x と v2.0 の併用は非推奨とされている |
| 転換期限 | **割当日の18か月後の応当日**。次回株式資金調達が転換期限までに発生しない場合、発行要項所定の承認（発行要項(5)(b)）を経て、キャップ ÷ 完全希釈化後株式数を転換価額として行使可 | この場合の転換先は原則として普通株式（発行要項(1)(a)） |
| 支配権移転取引（買収）時 | **発行価額の2倍**の金銭による取得、又はキャップで転換 | |
| 主要投資家 | 払込金額 **[500万円] 以上**の者に情報請求権等を付与 | |
| 転換先 | 適格調達時は当該調達で発行される種類の株式（調整あり） | 詳細は発行要項参照 |

### 6.1.1 ひな形の使い方と、このツールでの扱い

### 6.2 会社法上の位置づけ
- 新株予約権の発行手続（法238条以下。非公開会社は株主総会特別決議）、新株予約権原簿への記載（法249条）、発行登記（法911条3項12号、2週間以内）が必要。→ `03-stock-options.md`
- 払込金額は資本金に計上されず（新株予約権として純資産の部に計上）、**行使（転換）時**に資本金・資本準備金へ振り替わります。
- 行使による変更登記は月末締め2週間以内（法915条3項1号）。

### 6.3 税務・その他
- 国税庁 Q&A（令和6年11月改訂）問9 注記: 税制適格ストックオプションの株価算定（特例方式）において、J-KISS 型新株予約権など残余財産の優先分配を受けられる新株予約権は、優先株式と同様に取り扱って差し支えないとされています。
- エンジェル税制: Coral Capital のページでは「令和6年度税制改正により 2024年4月1日以降に取得した J-KISS は対象となり、控除の基準は行使時」と説明されています（**経済産業省・中小企業庁の一次資料では未確認**）。

## 7. 金融商品取引法の開示規制（概要）

### 7.1 現行法（2026-11-11時点で施行中）

| 概念 | 内容 | 根拠 |
|---|---|---|
| 募集（公募） | 新規発行有価証券の取得勧誘のうち、**50名以上**の者を相手方とするもの（適格機関投資家私募等の例外あり） | 金商法2条3項1号、同施行令1条の5 |
| 少人数私募 | 勧誘の相手方が**49名以下**で、多数の者に譲渡されるおそれが少ないもの。**人数は「取得者」ではなく「勧誘の相手方」で数える** | 金商法2条3項2号ハ、施行令1条の7 |
| 3か月通算 | 発行日以前**3か月以内**に同一種類の有価証券（同種の新規発行証券）を発行している場合、その勧誘対象者数と合算して50名以上になると「募集」に該当 | 施行令1条の6 |
| 有価証券届出書 | 募集・売出しは原則として届出が必要。ただし**発行価額の総額が1億円未満**のものは不要（内閣府令で定める通算に注意） | 金商法4条1項5号 |
| 1億円の通算 | 募集開始日前**1年以内**の同一種類の有価証券の募集・売出しの額を合算（新株予約権は行使価額の合計額も合算） | 開示府令2条5項 |
| 有価証券通知書 | 届出不要の募集・売出しのうち、発行価額の総額が**1,000万円を超え1億円未満**のものは、開始前に財務局長等へ通知書を提出。**1,000万円以下は不要** | 金商法4条6項、開示府令4条1項・5項 |
| ストックオプションの特例 | 発行会社又はその子会社（開示府令2条3項）の取締役・会計参与・監査役・執行役・使用人を相手方とする、**譲渡禁止の制限が付された新株予約権証券**の取得勧誘は届出不要 | 金商法4条1項1号、施行令2条の12第2号、開示府令2条2項 |
| 私募の告知 | 少人数私募等では、届出がされていない旨等の告知義務がある | 金商法23条の13（条文本文は未確認） |

**アプリ実装上の含意**
- 「勧誘した相手方」の人数（3か月通算）と、「募集」に該当する場合の発行価額の総額（1年通算）を追跡できるとよい。
- 少人数私募（49名以下への勧誘）に該当する限り、金額にかかわらず有価証券届出書・通知書は不要です。1億円・1,000万円の閾値が問題になるのは「募集」（50名以上への勧誘）に該当する場合です。
- 従業員50名以上へ一斉にストックオプションを付与する場合は、上記のストックオプション特例の要件（対象者の範囲・譲渡禁止）を確認する。**業務委託先等の外部協力者は特例の対象外**なので人数カウントに入る。

### 7.2 【重要】成立済み・未施行の改正（2027年4月1日施行予定）

「金融商品取引法及び資金決済に関する法律の一部を改正する法律」が**令和8年（2026年）4月10日に国会提出、同年7月15日に成立**しました（金融庁ウェブサイトで確認）。法律案要綱によれば、「成長資金供給の拡大に係る開示制度の見直し」に係る規定は**令和9年（2027年）4月1日施行**です。

| 改正点 | 現行 | 改正後（2027-04-01〜） |
|---|---|---|
| 有価証券届出書の提出免除基準 | 1億円未満 | **5億円未満** |
| 少額募集（簡易様式の届出書）の範囲 | 5億円未満 | **10億円未満** |
| 役員・使用人への株券・新株予約権証券の交付 | 上記7.1の届出免除（非上場会社の株式報酬は対象外） | 上場・非上場を問わず、自社及び子会社の役員・使用人への勧誘を**「募集・売出し」の定義から除外** |
| 特定投資家私募等 | — | 勧誘対象者の範囲を拡大 |

- 改正後の有価証券通知書の扱い（1億円以上5億円未満の募集について通知書提出・公衆縦覧の対象とする等）は、法律事務所の解説（二次情報）では確認しましたが、**改正後の条文・内閣府令は未確認**です。施行前に必ず再確認してください。
- 公布日（2026年7月23日）は二次情報による。
- アプリでは閾値を定数ではなく**適用日付きの設定値**として持つことを推奨します。
