# 04 株主総会

> **免責**: 本書は非公開会社である株式会社を主な対象とした一般的な要約であり、法的助言ではありません。定款に別段の定めがある場合は定款が優先することがあります。個別案件は弁護士・司法書士に確認してください。
> **確認日**: 2026-11-11（e-Gov 法令検索 API で同日取得した現行条文に基づく）
> **表記**: 「法」＝会社法、「施規」＝会社法施行規則。

## 1. 定時株主総会・臨時株主総会（法296条）

- **定時株主総会**は、毎事業年度の終了後**一定の時期**に招集しなければならない（法296条1項）。会社法自体は「3か月以内」とは定めていません。
- 議決権の基準日を事業年度末日とする定款の定めがある場合、基準日株主の権利は基準日から**3か月以内**に行使するものに限られる（法124条2項）ため、結果として**事業年度末日から3か月以内**の開催が必要になります。
- 法人税の確定申告は事業年度終了の日の翌日から**2か月以内**（法人税法74条1項。延長の特例あり）で、「確定した決算」に基づくため、申告期限との整合も必要です。→ `06-financial-disclosure.md`
- 臨時株主総会は必要があるときいつでも招集できる（法296条2項）。
- 取締役会設置会社の株主総会は、法令・定款所定の事項に限り決議できる（法295条2項）。また、招集時に定めた目的事項以外は決議できない（法309条5項）。

## 2. 招集の決定（法298条）

| 決定事項 | 根拠 |
|---|---|
| 日時及び場所 | 法298条1項1号 |
| 目的事項（議題） | 同2号 |
| 書面投票を認めるときはその旨 | 同3号 |
| 電子投票を認めるときはその旨 | 同4号 |
| 法務省令で定める事項（定時総会の日が前年と著しく離れた日である場合の理由、過去の開催場所と著しく離れた場所とする場合の理由、書面・電子投票を定めた場合の参考書類記載事項・行使期限 等） | 同5号、施規63条 |

- **取締役会設置会社では取締役会決議**による（法298条4項）。非取締役会設置会社では取締役（複数の場合は過半数。法348条2項・3項3号）。
- 議決権を行使できる株主が**1,000人以上**の場合は書面投票が義務（法298条2項）。

## 3. 招集通知の発送期限（法299条）

| 会社の類型 | 発送期限（株主総会の日の…前まで） | 方法 | 根拠 |
|---|---|---|---|
| 公開会社 | **2週間** | 書面（株主の承諾があれば電磁的方法） | 法299条1項〜3項 |
| 非公開会社・**取締役会設置会社** | **1週間** | 書面（同上） | 同上 |
| 非公開会社・**取締役会非設置会社** | **1週間**（**定款でこれを下回る期間を定めた場合はその期間**） | 書面でなくてもよい（口頭・メール等も可） | 同1項かっこ書、2項 |
| **書面投票又は電子投票を定めた場合**（会社類型を問わない） | **2週間** | 書面（同上） | 同1項かっこ書、2項1号 |

- 「○週間前まで」は、発送日と総会日の間に**中○週間（丸7日／14日）**が必要と解されています（発信日・総会日を算入しない。民法の期間計算と確立した実務・判例による。条文上の明記はないためアプリでは「発送期限日 = 総会日 − (N×7 + 1) 日」として安全側に計算することを推奨）。
- 通知には法298条1項各号の事項を記載・記録（法299条4項）。
- **電磁的方法による通知**には個々の株主の**承諾**が必要（法299条3項）。アプリで招集通知をメール送信する場合、取締役会設置会社では株主ごとの承諾の記録を保持してください。
- 取締役会設置会社の定時総会では、招集通知に際して計算書類・事業報告（監査報告を含む）を提供（法437条）。
- 電子提供措置（法325条の2以下。総会の3週間前又は招集通知発送日のいずれか早い日から掲載）は定款の定めが必要で、上場会社等（振替株式発行会社）以外は任意です。本書では詳細を扱いません。

## 4. 招集手続の省略（法300条）

- **株主全員の同意**があるときは、招集手続を経ずに開催できる。
- ただし、**書面投票・電子投票を定めた場合は省略不可**（同ただし書）。
- 同意の方式に法律上の制限はありませんが、証拠として書面・電磁的記録で取得しておくのが実務です。

## 6. 議決権の行使方法

| 方法 | 要点 | 根拠 |
|---|---|---|
| 代理行使 | 代理権を証明する書面（**委任状**）を会社に提出。**授権は総会ごと**。会社の承諾を得て電磁的方法による提供も可。代理人の数は制限可 | 法310条1項〜5項 |
| 書面投票 | 議決権行使書面を、**総会の日時の直前の営業時間の終了時**（招集決定で特定の時を定めた場合はその時）までに提出 | 法311条1項、施規69条 |
| 電子投票 | 会社の承諾を得て、同上の時までに電磁的方法で提供 | 法312条1項、施規70条 |
| **備置き** | 委任状、議決権行使書面、電子投票の記録は、**株主総会の日から3か月間**本店に備置き。株主は理由を明らかにして閲覧・謄写請求可（拒絶事由あり） | 法310条6項〜8項、311条3項〜5項、312条4項〜6項 |

## 7. 書面決議（決議の省略・法319条）と報告の省略（法320条）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 決議の省略 | 取締役**又は株主**の提案について、議決権を行使できる**株主全員**が**書面又は電磁的記録**で同意の意思表示をしたとき、可決の決議があったものとみなす。**定款の定めは不要**（取締役会の書面決議と異なる） | 法319条1項 |
| 同意書面の備置き | 決議があったとみなされた日から**10年間**本店に備置き。株主・債権者は閲覧・謄写請求可 | 同2項・3項 |
| 定時総会の場合 | 定時総会の目的事項の全てについて書面決議が成立したときは、その時に定時総会が終結したものとみなす（役員任期の満了時点に影響） | 同5項 |
| 報告の省略 | 取締役が株主全員に報告事項を通知し、報告を要しないことに株主全員が書面又は電磁的記録で同意したとき、報告があったものとみなす | 法320条 |
| 議事録 | 書面決議・報告省略の場合も**議事録の作成が必要**（記載事項は下記8.2） | 施規72条4項 |
| 計算書類等の備置開始日 | 書面決議の場合は**提案があった日**から | 法442条1項1号かっこ書 |
| 登記 | 議事録に代えて「決議があったものとみなされる場合に該当することを証する書面」を添付。株主リストも必要 | 商業登記法46条3項 |

**アプリ実装上の含意**: 書面決議のみなし決議日は「最後の株主の同意が会社に到達した日」（提案で効力発生日を定める実務もある）。全員分の同意の到達日時を記録する。

## 8. 議事録（法318条、施規72条）

### 8.1 作成・備置き

| 項目 | 内容 | 根拠 |
|---|---|---|
| 作成義務 | 書面又は電磁的記録で作成 | 法318条1項、施規72条2項 |
| 本店備置き | 株主総会の日から**10年間** | 法318条2項 |
| 支店備置き | 写しを**5年間**（電磁的記録で作成し、支店で閲覧に応じられる措置をとっている場合は不要） | 同3項 |
| 閲覧・謄写 | **株主及び債権者**は営業時間内いつでも請求可（理由の明示・拒絶事由の規定なし）。親会社社員は裁判所の許可 | 同4項・5項 |
| 署名・押印 | **会社法上、株主総会議事録への署名・記名押印義務はない**（取締役会議事録と異なる）。ただし定款で定めている会社が多く、また代表取締役選定を株主総会で行った場合等は登記実務上押印（又は電子署名）が必要になる場面がある（商業登記規則61条。本書では条文未確認） | — |

### 8.2 記載事項（施規72条3項・4項）

**通常開催の場合（3項）**
1. 開催された日時及び場所（当該場所に存しない取締役・監査役・株主等が出席した場合は**その出席の方法**。Web 会議参加者等）
2. 議事の経過の要領及びその結果
3. 法定の意見・発言があるときはその内容の概要（監査役の選任・解任・辞任に関する意見（法345条）、監査役の報酬に関する意見（法387条3項）、監査役による議案等の調査結果の報告（法384条、389条3項）、会計参与・会計監査人の意見 等）
4. 出席した取締役、執行役、会計参与、監査役又は会計監査人の氏名又は名称
5. 議長が存するときは議長の氏名
6. 議事録の作成に係る職務を行った取締役の氏名

**書面決議（法319条1項）の場合（4項1号）**
- 決議があったものとみなされた事項の内容／提案をした者の氏名又は名称／決議があったものとみなされた日／議事録作成に係る職務を行った取締役の氏名

**報告の省略（法320条）の場合（4項2号）**
- 報告があったものとみなされた事項の内容／みなされた日／議事録作成に係る職務を行った取締役の氏名

## 9. 株主提案権（法303条〜305条）

| 権利 | 非取締役会設置会社 | 取締役会設置会社（非公開） | 取締役会設置会社（公開） | 根拠 |
|---|---|---|---|---|
| **議題提案権**（一定の事項を総会の目的とすることの請求） | 単独株主権。期限の定めなし | 総株主の議決権の**1%以上**又は**300個以上**。**保有期間要件なし**。総会の日の**8週間前まで**に請求 | 同左＋**6か月前から引き続き保有** | 法303条 |
| **議案提出権**（総会の場での動議） | 単独株主権 | 単独株主権（目的事項の範囲内） | 同左 | 法304条 |
| **議案要領通知請求権**（招集通知への記載請求） | 単独株主権。総会の日の8週間前まで | 1%以上又は300個以上。保有期間要件なし。**8週間前まで** | 同左＋6か月保有 | 法305条1項・2項 |

- 1%・300個・6か月・8週間は、いずれも**定款で引き下げ・短縮可能**。
- 議案提出・通知請求が認められない場合: 法令・定款違反の議案、実質的に同一の議案が総株主の議決権の**10分の1以上**の賛成を得られなかった日から**3年**を経過していない場合（法304条ただし書、305条6項）。
- 取締役会設置会社では、議案要領通知請求できる議案数は**10まで**（役員選任・解任等はそれぞれ1議案と数える）（法305条4項）。

| 株主名簿・株主総会議事録・計算書類等の閲覧 | 単独 | — | — | 法125条、318条、442条 |
| 取締役会議事録の閲覧 | 単独。**監査役設置会社等では裁判所の許可**が必要 | — | — | 法371条2項・3項 |
| 取締役会の招集請求 | 単独。**監査役設置会社・監査等委員会設置会社・指名委員会等設置会社を除く**取締役会設置会社のみ | — | — | 法367条 |

- 「監査役設置会社」には、監査役の監査範囲を会計に関するものに限定している会社（法389条）は**含まれません**（法2条9号）。会計限定監査役しか置いていない非公開会社では、株主の権限が強化されます（例: 取締役会議事録を裁判所の許可なく閲覧可、法360条の差止要件が「著しい損害」）。
- 3%・10%等の計算では、当該事項について議決権を行使できない株主の議決権、自己株式は分母から除かれます（各条かっこ書）。

## 11. 計算書類の承認・事業報告・決算公告

| 項目 | 内容 | 根拠 |
|---|---|---|
| 計算書類・事業報告の提出 | 取締役は（監査・取締役会承認を経た）計算書類及び事業報告を定時株主総会に提出・提供 | 法438条1項 |
| 計算書類の**承認** | 定時株主総会の承認（普通決議）を受ける | 法438条2項 |
| 事業報告 | 内容を定時株主総会に**報告**（承認事項ではない） | 法438条3項 |
| 会計監査人設置会社の特則 | 一定の要件（無限定適正意見等）を満たす場合、計算書類は承認不要で**報告**で足りる | 法439条 |
| **決算公告** | 定時株主総会の**終結後遅滞なく**、**貸借対照表**（大会社は貸借対照表及び損益計算書）を公告 | 法440条1項 |

決算公告の方法の詳細、計算書類の備置き・閲覧は `06-financial-disclosure.md` を参照。

## 12. 動向（未施行・検討中）

- 法制審議会 会社法制（株式・株主総会等関係）部会が2026年3月に「会社法制（株式・株主総会等関係）の見直しに関する中間試案」を取りまとめ、法務省が同年4月〜5月にパブリックコメントを実施したと報じられています（従業員等への株式無償交付、バーチャル株主総会の会社法への規定、実質株主確認制度 等）。**2026-11-11時点で改正法は成立していません**（二次情報による。法務省サイトでの直接確認は未実施）。
- 場所の定めのない株主総会（バーチャルオンリー株主総会）は、現行法上、産業競争力強化法66条により**上場会社**に限り認められています。非上場会社は、物理的な会場を設けたうえでの Web 参加（ハイブリッド型）となります。
