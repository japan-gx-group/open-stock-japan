# 06 決算情報の作成・備置き・株主への開示

> **免責**: 本書は非公開会社である株式会社を主な対象とした一般的な要約であり、法的助言・税務助言ではありません。投資契約に関する記述は一般的な実務の紹介であり、個別の契約条項が優先します。個別案件は弁護士・税理士・公認会計士に確認してください。
> **確認日**: 2026-11-11（e-Gov 法令検索 API で同日取得した現行条文に基づく）
> **表記**: 「法」＝会社法、「施規」＝会社法施行規則、「計規」＝会社計算規則、「個情法」＝個人情報の保護に関する法律。

## 1. 作成すべき書類（法435条）

| 書類 | 内容 | 根拠 |
|---|---|---|
| **計算書類** | 貸借対照表、損益計算書、**株主資本等変動計算書**、**個別注記表** | 法435条2項、計規59条1項 |
| **事業報告** | 会社の状況に関する重要な事項 等（計算書類の内容となる事項を除く） | 法435条2項、施規118条 |
| **附属明細書** | 計算書類の附属明細書、事業報告の附属明細書 | 法435条2項 |
| 成立の日の貸借対照表 | 設立時 | 法435条1項 |

- 電磁的記録で作成可（法435条3項）。
- **保存**: 計算書類及びその附属明細書は、作成した時から**10年間**保存（法435条4項）。会計帳簿及び事業に関する重要な資料は、帳簿閉鎖の時から**10年間**保存（法432条2項）。
- 事業年度は**1年を超えられない**（事業年度の末日を変更する場合の変更後最初の事業年度は1年6か月まで）（計規59条2項）。
- 事業報告の記載事項は会社類型（公開会社か、会計監査人設置会社か等）により増減します。非公開会社は公開会社向けの追加記載事項（施規119条以下）の多くが不要です（詳細は本書では未確認）。

## 2. 監査・承認の流れ（法436条〜438条）

| ステップ | 内容 | 期限・備考 | 根拠 |
|---|---|---|---|
| ① 作成 | 取締役が計算書類・事業報告・附属明細書を作成 | — | 法435条2項 |
| ② 監査役の監査 | **監査役設置会社（会計限定監査役の会社を含む。会計監査人設置会社を除く）**では監査役の監査を受ける | 監査報告の通知期限: 計算書類の全部を受領した日から**4週間**を経過した日、附属明細書を受領した日から**1週間**を経過した日、特定取締役・特定監査役の**合意により定めた日**のうち**いずれか遅い日**まで。事業報告も同様の定め | 法436条1項、計規124条1項、施規132条1項 |
| ②' 会計監査人の監査 | 会計監査人設置会社（非公開でも**大会社**は設置義務） | — | 法436条2項、328条2項 |
| ③ 取締役会の承認 | 取締役会設置会社では取締役会の承認 | — | 法436条3項 |
| ④ 株主への提供 | **取締役会設置会社**では、定時株主総会の**招集通知に際して**、承認を受けた計算書類・事業報告（監査報告・会計監査報告を含む）を株主に提供 | 招集通知と同じ期限（非公開・取締役会設置会社は総会の1週間前まで） | 法437条 |
| ⑤ 備置き開始 | 本店に備置き | 定時総会の**2週間前**（取締役会非設置会社は**1週間前**）の日から | 法442条1項 |
| ⑥ 定時株主総会 | 計算書類の**承認**（普通決議）、事業報告の**報告** | — | 法438条2項・3項 |
| ⑦ 決算公告 | 貸借対照表（大会社は貸借対照表及び損益計算書）を公告 | 定時総会の**終結後遅滞なく** | 法440条1項 |

- 監査期間は合意で伸長できますが、監査役の同意なく4週間より**短縮することはできない**と解されています（計規124条1項の構造上、合意した日が早くても「いずれか遅い日」が期限となるため）。監査役が期限前に監査報告を通知すれば、その日に監査を受けたものとされます（同2項）。
- 会計限定監査役は、会計に関する議案・書類を調査し、調査結果を株主総会に報告する（法389条3項）。
- 大会社: 最終事業年度の貸借対照表上の資本金が**5億円以上**又は負債合計額が**200億円以上**の会社（法2条6号）。大型調達で資本金が5億円以上となり、そのまま事業年度末を越えると、定時総会以降は会計監査人の設置が必要になります。資本金・資本準備金の配分（法445条）や減資の検討に影響します。

**アプリ実装上の含意（非公開・取締役会設置・監査役設置会社の定時総会の逆算）**

```
総会日 D
  D − 8日以前     招集通知の発送（中1週間）＋計算書類・事業報告・監査報告の提供（437条）
  D − 2週間       計算書類等の本店備置き開始（442条1項。取締役会設置会社）
  それ以前        取締役会による計算書類等の承認（436条3項）・総会招集決定（298条4項）
  それ以前        監査報告の受領（計算書類受領から原則4週間経過日まで待つ必要があり得る）
```

※ 招集通知は1週間前で足りますが、**備置きは2週間前から**必要なため、取締役会の計算書類承認は遅くとも総会の2週間前の日までに完了している必要があります。

## 3. 計算書類等の備置き・閲覧（法442条）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 対象 | 各事業年度の計算書類・事業報告・これらの附属明細書（監査報告・会計監査報告を含む）、臨時計算書類 | 法442条1項 |
| 本店備置期間 | 定時株主総会の日の**1週間前**（**取締役会設置会社は2週間前**）の日から**5年間**。書面決議（法319条1項）の場合は**提案があった日**から5年間 | 同1項1号 |
| 支店備置期間 | 写しを同じ起算日から**3年間**（電磁的記録で作成し、支店で閲覧に応じられる措置をとっている場合は不要） | 同2項 |
| 請求権者 | **株主及び債権者**。営業時間内いつでも。**理由の明示は不要**で、拒絶事由の定めもない | 同3項 |
| 請求できる内容 | ①書面の閲覧、②謄本・抄本の交付、③電磁的記録の表示の閲覧、④電磁的記録の電磁的方法による提供又は書面の交付。**②④は会社の定めた費用の支払が必要** | 同3項 |
| 親会社社員 | 裁判所の許可を得て請求可 | 同4項 |

- 株主名簿（法125条）や会計帳簿（法433条）と異なり、計算書類等の閲覧は**1株の株主でも、理由を示さずに**請求できます。アプリで「株主向けに計算書類を常時開示」する機能は、この閲覧請求への対応を効率化するものと位置づけられます。
- 債権者にも閲覧請求権があるため、「株主のみ閲覧可」とするアクセス制御は、会社法上の義務を超える部分（月次情報等）と法定書類とで分けて設計するのが適切です。

## 4. 会計帳簿閲覧謄写請求権（法433条）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 持株要件 | 総株主の議決権の**3%以上**、又は発行済株式（**自己株式を除く**）の**3%以上**（いずれも定款で引下げ可）。**保有期間要件なし** | 法433条1項 |
| 対象 | 会計帳簿又はこれに関する資料（総勘定元帳、仕訳帳、補助簿、伝票・契約書等の資料が含まれ得る。範囲は解釈による） | 同1項 |
| 手続 | 営業時間内いつでも。**請求の理由を明らかにする**必要あり | 同1項後段 |
| 拒絶事由 | ①権利の確保・行使に関する調査以外の目的、②業務遂行を妨げ株主共同の利益を害する目的、③請求者が会社の業務と**実質的に競争関係にある事業を営み、又はこれに従事**するものであるとき、④知り得た事実を利益を得て第三者に通報するため、⑤過去2年以内に同様の通報をしたことがあるとき | 同2項 |
| 親会社社員 | 裁判所の許可を得て請求可 | 同3項 |

- 3%は複数の株主の持株を合算して満たすこともできると解されています（解釈）。
- 競合他社や競合に出資する投資家が株主にいる場合、③の拒絶事由が問題になります。

## 5. 決算公告（法440条・939条）

| 公告方法（定款の定め） | 公告の内容 | 根拠 |
|---|---|---|
| **官報**（定款に定めがない場合のデフォルト） | 貸借対照表の**要旨**で足りる | 法939条1項1号・4項、440条2項 |
| 日刊新聞紙 | 貸借対照表の**要旨**で足りる | 法939条1項2号、440条2項 |
| **電子公告** | 貸借対照表の**全文**を、定時総会終結の日後**5年を経過する日まで**継続して掲載 | 法939条1項3号、940条1項2号 |
| 官報・新聞を公告方法とする会社の特例 | 貸借対照表の内容を、定時総会終結の日後**5年を経過する日まで**継続してウェブサイトに掲載する措置をとれば、官報等での決算公告は不要。この場合の URL は登記事項 | 法440条3項、911条3項26号 |
| 有価証券報告書提出会社 | 決算公告不要 | 法440条4項 |

- 大会社は貸借対照表及び損益計算書（法440条1項）。
- 公告すべき注記事項は計規136条。要旨の区分は計規137条以下。
- 決算公告を怠った場合は**100万円以下の過料**の対象（法976条2号）。
- 決算公告は株式会社の義務であり、非公開会社・中小会社にも例外はありません（特例有限会社を除く。会社法の施行に伴う関係法律の整備等に関する法律。本書では条文未確認）。

## 6. 法人税の申告期限（法人税法74条・75条の2）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 原則 | 各事業年度終了の日の翌日から**2か月以内**に、**確定した決算**に基づき確定申告書を提出 | 法人税法74条1項 |
| 延長の特例（原則） | 定款等の定め又は特別の事情により、事業年度終了の日の翌日から2か月以内に定時総会が招集されない常況にあると認められる場合、申請により提出期限を**1か月間**延長（＝事業年度末から3か月） | 同75条の2第1項柱書 |
| 延長の特例（会計監査人設置会社） | 会計監査人を置き、かつ定款等の定めにより3か月以内に定時総会が招集されない常況にある場合、**4か月を超えない範囲内**で税務署長が指定する月数 | 同項1号 |
| 申請 | 最初に適用を受けようとする**事業年度終了の日まで**に申請書を提出。定款の写しを添付（定款の定めを理由とする場合） | 同3項・4項 |

- 「確定した決算」とは、定時株主総会で承認（又は報告）された計算書類を指すのが原則です。そのため、3月決算会社が6月に定時総会を開催する場合は、延長の特例の申請が必要です。
- 延長期間中も**利子税**がかかるため、見込納付を行うのが実務です（利子税の規定は本書では未確認）。
- 法人住民税・法人事業税（地方税法）、消費税（消費税法45条の2による延長特例）は、それぞれ別途の届出・申請が必要です（本書では条文未確認）。

**定時株主総会の時期の整理**

| 制約 | 期限 | 根拠 |
|---|---|---|
| 基準日（事業年度末日）の効力 | 事業年度末から**3か月以内** | 法124条2項 |
| 法人税申告（延長なし） | 事業年度末の翌日から**2か月以内**に決算確定＝総会承認 | 法人税法74条1項 |
| 法人税申告（延長1か月） | 事業年度末の翌日から**3か月以内** | 同75条の2第1項 |

## 7. 投資契約・株主間契約上の情報請求権との関係（一般的な実務）

以下は法令ではなく、スタートアップ投資における**一般的な契約実務**の紹介です。具体的内容は各契約によります。

| 観点 | 会社法上の権利 | 投資契約・株主間契約での典型的な上乗せ |
|---|---|---|
| 対象者 | 全株主（計算書類）／3%以上（会計帳簿） | 投資家（一定の持株比率・出資額以上の「主要投資家」に限定することも多い） |
| 年次決算 | 計算書類・事業報告（定時総会前） | 事業年度終了後○日以内に計算書類・税務申告書の写し等を提出 |
| 月次・四半期 | **法定の権利なし** | 月次試算表・四半期決算・KPI を毎月／四半期末後○日以内に提出 |
| 事業計画・予算 | 法定の権利なし | 年度予算・事業計画を事業年度開始前に提出、又は事前承諾・事前協議事項 |
| その他 | 株主名簿・議事録の閲覧 | 資本政策表（キャップテーブル）の提出、重要事項の事前通知・事後報告、オブザーバー派遣権、帳簿・施設への立入調査権 |

- 経済産業省は「我が国における健全なベンチャー投資に係る契約の主たる留意事項」等で投資契約の考え方を公表しています（**本書の確認日時点で最新版の内容は未確認**）。
- J-KISS 2.0 のひな形では、払込金額が一定額（ひな形の初期値: 500万円）以上の「主要投資家」に情報請求権等を付与する構成です。→ `02-share-issuance.md`
- **株主平等原則との関係**: 契約に基づき特定の投資家にのみ追加情報を提供すること自体は一般に行われていますが、未公表の重要情報を一部の株主にのみ提供する場合の取扱い（守秘義務、他の株主との公平、上場準備段階でのインサイダー情報管理）は弁護士に確認してください。

**アプリ実装上の含意**: 開示対象を「①法定書類（全株主・債権者が請求可）」「②契約上の開示（契約当事者である投資家のみ）」「③任意の IR」に区分し、文書ごとに閲覧権限と提出期限（契約上の○日以内）を設定できるようにする。

## 8. 個人情報保護法上の株主情報の取扱い

株主名簿・新株予約権原簿には個人株主・個人新株予約権者の氏名・住所が含まれ、これらをデータベースとして事業に用いる会社は**個人情報取扱事業者**に当たります（個情法16条2項）。

| 論点 | 内容 | 根拠 |
|---|---|---|
| 利用目的 | 取得時に利用目的を通知・公表（本人から直接書面等で取得する場合はあらかじめ明示）。会社法上の義務の履行（名簿作成・通知・配当等）や株主管理を目的として特定しておく | 個情法17条・21条 |
| 安全管理措置 | 漏えい・滅失・毀損の防止その他の安全管理のために必要かつ適切な措置 | 個情法23条 |
| 委託先の監督 | クラウドサービス提供者・株主名簿管理人・司法書士等へ取扱いを委託する場合の監督 | 個情法25条 |
| **第三者提供の制限** | 原則として本人の同意なく個人データを第三者に提供できない。ただし「**法令に基づく場合**」は同意不要 | 個情法27条1項1号 |
| 株主名簿の閲覧請求への対応 | 会社法125条2項に基づく株主・債権者からの閲覧謄写請求に応じることは「法令に基づく場合」に当たると解されます（**個人情報保護委員会のガイドライン・Q&A での明示的な記載は本書では未確認**）。他方、会社法上の拒絶事由（法125条3項）がある請求に任意に応じる場合や、法定の請求権に基づかない提供（例: 投資家候補へのキャップテーブル共有）は、本人同意その他の根拠が必要になり得ます | 個情法27条1項、法125条 |
| 登記・法定調書 | 株主リストの登記所への提出、法定調書の税務署への提出は法令に基づく提供 | 商業登記規則61条、措法29条の2第6項 等 |
| 本人からの開示請求 | 保有個人データの開示請求に対応 | 個情法33条 |
| マイナンバー | 配当の支払調書、SO の法定調書等で個人番号を取り扱う場合は番号法の規制（利用目的の限定、安全管理措置、提供制限）が別途かかります（本書では未確認） | — |

**アプリ実装上の含意**
- 株主が他の株主の氏名・住所・持株数を閲覧できる機能は、会社法125条の閲覧請求（理由の明示・拒絶事由の審査）を経ずに常時開示することになるため、デフォルトでは**他の株主の住所等を表示しない**設計とし、会社の判断で開示範囲を設定できるようにするのが安全です。
- 投資家向けキャップテーブル共有では、個人株主（エンジェル・従業員）の氏名・持株数が含まれる点に留意し、共有範囲を記録する。
- アクセスログ、暗号化、権限管理、データ所在地等は安全管理措置（個情法23条）の一環として設計する。
